# 🎙️ Legion Of Vocals (LOV-Portal)

A modern, high-performance web portal for **Legion Of Vocals** — an anime and multimedia voice dubbing organization. Built with React 19, Tailwind CSS v4, Framer Motion, and Vite.

---

## ✨ Features

- **🎬 Interactive Showcase & Hero:** Engaging hero section with dynamic video background, live stats, and banner previews.
- **📺 Dubbed Projects & Videos:** Full media browser with custom video players, category filtering, reactions, and sharing features.
- **🏆 Tournaments & Contests:** Voice dubbing competitions, round tracking, and real-time interactive leaderboards.
- **👥 Team & Member Profiles:** Comprehensive member directory with skill showcases, voice samples, social links, and tier badges.
- **🛡️ Admin Dashboard:** Management suite for approving pending applicant registrations, scoring tournament rounds, managing team rosters, and publishing projects.
- **💬 Community Messenger:** Integrated floating real-time messenger and notification center.
- **📝 Join LOV Application Flow:** Step-by-step registration stepper with voice sample demo uploads.

---

## 🛠️ Tech Stack

- **Frontend:** [React 19](https://react.dev/)
- **Build Tool:** [Vite](https://vite.dev/)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **Icons:** [Lucide React](https://lucide.dev/) & [React Icons](https://react-icons.github.io/react-icons/)
- **Routing:** [React Router v7](https://reactrouter.com/)

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Zamiul-Hasan/Legion-Of-Vocals.git
   cd Legion-Of-Vocals
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
